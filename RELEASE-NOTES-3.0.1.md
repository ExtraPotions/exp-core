# exp-core 3.0.1

Shared site/plugin diagnostics with compact scrollable Show/Copy controls, page structure and performance summaries, privacy exclusions, and keyboard access. Width-aware menu contracts, red recovery styles, and expanded cross-product regression checks.

Existing V3 settings are preserved. Approved artwork is unchanged.
Diagnostics stay local; page text, form values, URL queries, and unrelated storage are excluded by the shared diagnostics helper.
