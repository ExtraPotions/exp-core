# exp-core

**A familiar menu across ExtraPotions.**

exp-core is the shared menu included with every ExtraPotions product. There's nothing to install separately.

[![Code: PolyForm Noncommercial 1.0.0](docs/badges/code.svg)](LICENSE-CODE.md)
[![Artwork and documentation: CC BY-NC-SA 4.0](docs/badges/assets.svg)](LICENSE-ASSETS.md)

## What you get

- **One layout everywhere:** every product groups its settings into the same sections with compact tabs, in the product's own colors.
- **Readable at any size:** choose Standard, Large, or Extra Large text in Appearance > Menu.
- **Clear status:** System shows whether the product is Working, Waiting, Paused, or Needs attention, and offers a fix when there is one.
- **Easy help:** copy diagnostics or report a problem from System > Support.
- **Launchers that stay out of the way:** drag them along the right edge, or use Alt+Arrow keys to reorder them.
